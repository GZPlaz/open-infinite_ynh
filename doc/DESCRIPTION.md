OpenInfinite generates printable math worksheets with answer keys and step-by-step solutions — an open-source alternative to Kuta Software's Infinite series.

Everything is computed in the browser of whoever uses it: problem generation, worked solutions, figures, page layout and PDF export. The server only serves static files, so the app needs essentially no CPU or memory and runs happily on a Raspberry Pi.

### Features

- 24 topics from Pre-Algebra to Calculus: equations and inequalities, systems, polynomials and factoring, exponents and radicals, the quadratic formula, matrices, the Pythagorean theorem, trigonometry, area and volume, angles, coordinate geometry, transformations, sequences, vectors, limits, derivatives and integrals
- Easy / Medium / Hard tiers and per-topic options (integer or fractional answers, negative numbers, exact or rounded answers, units…)
- Free-response or multiple-choice problems
- One-click answer key with optional worked solutions
- Layout controls: 1–3 columns, work space, Name/Date/Period/Score fields, US Letter or A4
- Regenerate everything or a single problem, reorder by drag-and-drop, edit any problem by hand, undo/redo
- Print with exact page breaks, or export PDF, LaTeX (with TikZ figures) and JSON
- Worksheets are saved in the browser; nothing is stored on the server
- Works offline once loaded
